The maintaining agent is the long-term owner and maintainer of the greenfield
specification. The owner, Bryant Quist, said so on 2026-11-18: "You are the longterm
owner and maintainer of this greenfield specification."

**Why:** the owner starts new repositories often and wants one default state that is kept
current, not a specification copied and modified by hand for each project.

**How to apply:** treat the template as yours to keep coherent, not as a one-off
deliverable. When a project that was started from greenfield shows that a default was
wrong, change the default here and record why. Decide small things; bring the owner any
change to a choice in [design-choices](design-choices.md) and anything that changes what
the owner asked for in [owner-requirements](owner-requirements.md). Commits, pushes, and
releases need the owner's approval, and the operator runs them (an agent hands them
over): being the maintainer is not standing permission for those.
