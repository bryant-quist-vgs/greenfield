# Out of scope

Things @@PROJECT_NAME@@ deliberately does not do, why, and what would cause the boundary to
be reconsidered. Work that belongs to the project but is not being done yet is in
[deferred-work.md](deferred-work.md). Terms are defined in the
[glossary](glossary.md#definitions).

Each entry has this form. IDs run from OOS-1 and are never reused.

```
## OOS-<n> <what is not done>

What the project does not do, and why not.

**Reconsider if:** the change in the project's boundary that would bring it back.
```

> **GREENFIELD-STUB** Write the first entries while defining the MVP (backlog B002):
> everything a reader might expect this project to do that it will not. A project with no
> stated boundary has not finished its design.
